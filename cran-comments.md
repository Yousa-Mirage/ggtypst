## Package size

The source tarball is 45.3 MB, of which 43.3 MB is `src/rust/vendor.tar.xz`.

ggtypst compiles the Typst typesetting engine from source with Rust. Following
CRAN's policy for packages using Rust, all Rust dependencies are vendored in
that archive (369 crates, 355 MB uncompressed), so the package installs without
downloading anything.

## Rust

* `SystemRequirements` declares Cargo and rustc >= 1.92.0 to compile the
  'typst' crate.
* This package's structure is generated by `rextendr`.
* When building for CRAN, `cargo build` runs offline (`--offline`) on the
  vendored crates.
